# Why this case exists

The header formula compares `r` against the string literal `"x #y"`, which
holds a space and a `#`.

§4.2 rule 6 and its grammar: `string = DQUOTE *( char - DQUOTE ) DQUOTE`,
so `#` and a space are string characters, and the formula is generated by
`formula`. §4.1.10: "**`#` inside a table line is data**, never an
annotation". §9.20 refuses a header cell "whose right-hand side is not
generated by §4.2's `formula`", and this one is.

The comparison is on text (§4.2 rule 10), so `x` is `5` in `r_1` and `0` in
`r_2`, and `g` is `5`. The refused neighbour is
`parse/hash-inside-a-formula-refused`, where the `#` is outside any string.
