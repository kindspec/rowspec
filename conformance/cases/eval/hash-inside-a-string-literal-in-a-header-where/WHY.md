# Why this case exists

The header group aggregate's predicate compares `r` against the string
literal `"x #y"`, which holds a space and a `#`.

§4.2's `group-call` carries a `predicate`, whose `pred-rhs` may be a
`string = DQUOTE *( char - DQUOTE ) DQUOTE`, so `#` and a space are string
characters and the formula is generated by `formula`. §4.1.10: "**`#` inside
a table line is data**, never an annotation". The declaration-line twin is
`eval/inline-annotation-scan-skips-string-literals`.

Equality compares text (§4.2 rule 6), so the predicate matches `r_1` and
`r_3`, and `t` is `16` in every row. `max(t)` is `16`; `count(t)` is `3`.
