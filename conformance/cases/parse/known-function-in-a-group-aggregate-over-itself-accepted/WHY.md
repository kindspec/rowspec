# Why this case exists

The control for
`parse/unknown-function-in-a-group-aggregate-over-itself-refused`: the same
cell with `min`, an `agg-fn`. It is generated by `group-call` (§4.2), `k` is
stored (§4.2 rule 5), and the column's reference to itself is a cycle, which
§4.2 rule 9 makes a value, not a refusal: such files "are **accepted files**,
not refusals". The file is accepted; `c` is `#REF!(cycle)`
(`rowrel/group-aggregate-over-itself-is-cycle` asserts that value for `sum`).
