# Why this case exists

§4.2 rule 4: "`sum (a where b = "x")` — with a space — is refused. The no-space
rule is §4.1's: `rhs` is written `ident "("` with no `*WSP` between them, and a
header-cell call spells its calls the same way."

It follows from rule 4's own mechanism: with a space, `sum` is not immediately
before `(`, so it is a column reference — and a column reference followed by a
parenthesised group is not generated by `expr`. §9.20 refuses it.
