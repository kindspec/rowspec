# Why this case exists

§4.2 rule 1: "`**`, `^`, `%`, `//` ... are **refused** rather than given a
meaning. `^` is the case that decides the policy: it is exponentiation in Excel,
Sheets, Lotus and every spreadsheet the users of this format have met, and
bitwise XOR in C, Python, Java and Go. Both readings are total functions over
numbers, neither raises, and `3 ^ 2` is `9` under one and `1` under the other —
the same file, two totals, no diagnostic."

§9.20 covers it: a header cell whose right-hand side is not generated by §4.2's
`formula`. Note the rule the spec attaches to the list — "The list above is not
the rule. **The rule is that `expr` is exactly what the ABNF generates**" — so
these four are samples of a closed grammar, not a denylist to be enumerated.
