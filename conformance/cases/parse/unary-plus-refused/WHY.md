# Why this case exists

§4.2's grammar has one unary operator: `factor = [ "-" *WSP ] primary`. There is
no `+` alternative, so `+a` is not generated by `formula` and §9.20 refuses the
header cell.

It is the same objection §4.1.6 makes to a leading `+` on a number — "a second
spelling of a value that already has one" — one level up, in the expression
language rather than in the cell.

`rowspec_alt` accepts it and returns 6.0.
