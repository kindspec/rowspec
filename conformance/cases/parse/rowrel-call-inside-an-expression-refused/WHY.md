# Why this case exists

§4.2 rule 3: "`cumulative(a) * 2`, `sum(a where b = "x") + 1` and
`prior(a) - a` are refused. A `call` never appears as a `primary`, and `expr`
has no call alternative."

The spec states the measured consequence of not refusing it, and this file is
that measurement: "handed `| x = cumulative(a) * 2 |` under a declared order,
the reference implementation matches neither the row-relative shape nor an
arithmetic one, leaves every `x` cell blank, and reports `0` for `sum(x)`. A
plausible zero is the failure §1 exists to prevent. A refusal is not."

§9.20 is the refusal: a header cell whose right-hand side is not generated by
§4.2's `formula`.
