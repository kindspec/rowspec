# Why this case exists

§4.2: `rowrel-call = rowrel-fn "(" *WSP ident *WSP ")"` — the argument is an
`ident`, never an `expr`, so `cumulative((amt))` is not generated by
`formula` and the header cell is refused (§9.20). Rule 10's parenthetical
depends on this: `cond` is "the **only** call whose parenthesis can [count
toward §9.23's 64], because `rowrel-call` and `group-call` take an `ident`
and so contain no `expr` to nest." An implementation that parses a call
argument with its general expression parser accepts this file and has
acquired a nesting site the grammar does not have.

`order := by(day)` is declared so that exactly one refusal applies (§9's
closing note): without it §9.9 would fire too.
